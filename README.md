# Wylie Colorguard Digest

A calm, mobile friendly daily digest for the Wylie HS colorguard, built from the BAND app groups (WHS Pure Gold Band and Wylie Color Guard).

Live page: https://wyliecolorguard.netlify.app

Refreshed twice daily at 5:00 AM and 5:00 PM Central. The page content lives in index.html between the DIGEST CONTENT START and END markers.
